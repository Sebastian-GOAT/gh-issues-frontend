# Github issues app

(Still figuring out a name for this app)

## Description

An web app for open-source contributors. You can search through Github issues,
filter by tags, languages and more. Perfect for people that are just getting into
open-source.

## Tech stack

**Frontend**

- NuxtJs
- TypeScript
- Tailwind CSS

**Backend**

- NestJs
- TypeScript
- Supabase (Auth + PostgreSQL)

**External APIs**

- Github API
- Gemini API

**API communication**

- REST
- GraphQL

**Deployment**

- Vercel (frontend + cron jobs)
- Render (backend)
